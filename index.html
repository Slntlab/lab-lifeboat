Backups are only half a plan. When a disk dies, an upgrade goes wrong or the house floods, you also need to know what to restore, in what order, and where the keys are. Lab Lifeboat turns your hosts, services and backups into a step-by-step restore runbook you keep offline or on paper.

Why a recovery pack?

  • The server holding your notes is the one that died. A pack on paper or on your phone survives it.
  • Restores fail on details: the wrong app version, a missing encryption key, a stale database file, different container paths. Each runbook calls these out.
  • Order matters. Bring back the hypervisor, then the password manager that holds every other secret, then the proxy, then the apps.
  • It finds the gaps. Lab Lifeboat warns when a service has no backup location, no offsite copy or no restore test on record.

How it works

  1. Add the machines you run (name, IP, OS).
  2. Add each service with its compose folder, data paths, backup location and offsite copy.
  3. Write where each secret lives, never the secret itself.
  4. Print the pack or save it as a PDF, and store a copy away from the server. Export the JSON with your backups.
  5. Do a restore drill, then record the date in “Last restore test”. Add a quarterly restore-drill reminder to your calendar (.ics).

FAQ

Is Lab Lifeboat really free?

Yes. It is free, needs no account, and has no ads or affiliate links inside the tool.

What is a homelab disaster recovery plan?

A written list of what you run, where its data and backups live, and the exact steps to bring each service back on new hardware. Lab Lifeboat builds that plan for you as step-by-step runbooks you can print.

Where is my data stored?

Only in this browser on this device (local storage). Nothing is uploaded. Export a JSON file to move it to another device or keep a copy with your backups.

Should I put passwords in it?

No. Lab Lifeboat records where each secret is kept, for example “Vaultwarden item Immich .env” or “paper sheet in the safe”. If a field looks like a real password, key or token, it warns you.

Does it work offline?

Yes. After the first visit the tool is cached on your device, so it opens without internet. You can also install it from your browser menu, and print the pack or save it as a PDF.

Which apps does it cover?

Built-in runbooks for Proxmox VE, Vaultwarden, Caddy, Home Assistant, Nextcloud AIO, Immich, Paperless-ngx and Jellyfin, plus custom services where you write your own steps.

Which versions are the runbooks written for?

Immich v3.3.6, Vaultwarden 1.37.5, Jellyfin v12.4, Nextcloud AIO v15.0.2, Caddy 2.11.9, Home Assistant 2026.11.1, Paperless-ngx v3.4.2 and Proxmox VE 9.2, checked against the official docs on 2026-11-10. Always restore the same version you backed up.

In what order should I restore my homelab?

Hypervisor first, then your password manager (the other secrets live there), then the reverse proxy, then the apps. Lab Lifeboat sorts your pack in that order.
